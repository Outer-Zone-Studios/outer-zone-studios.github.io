# outer-zone-studios.github.io

Website of Outer Zone Studios, served by GitHub Pages from this repo
(`Outer-Zone-Studios/outer-zone-studios.github.io`, branch `main`, root).

- `index.html`: studio page, links to each game's privacy policy.
- `privacy.html`: Bubbles & Tunnels privacy policy. Its URL goes in Play
  Console (App content > Privacy policy).
- `app-ads.txt`: to add once AdMob shows the publisher line
  (`google.com, pub-…, DIRECT, f08c47fec0942fa0`). It must stay at the site
  root. The Play listing's Website field must be https://outer-zone-studios.github.io.
- `.nojekyll`: serve files as they are.

Source text of the policy: `bubbles-and-tunnels/docs/privacy-policy.md`.
